# 📡 JioRouter AX6000 JIDU6J01 — Custom Firmware

Ye repo aapke **JioRouter AX6000 JIDU6J01** (JIDU6201/6401/6601/6701) ke liye roz automatically **OpenWrt** aur **ImmortalWrt** firmware banata hai.

> ⚠️ **Apni zimmedari par use karein.** Galat tarike se flash karne par router kharab (brick) ho sakta hai.

---

## 📱 Supported Device

| Config | Devices |
|---|---|
| `jidu6j01` | JioRouter AX6000 **JIDU6201 / 6401 / 6601 / 6701** |

---

## 🔄 Kitni baar naya firmware milega?

Har roz automatically 2 naye firmware ban jaate hain:
- **OpenWrt** — raat ~5:30 AM (IST)
- **ImmortalWrt** — subah ~7:30 AM (IST)

---

## ✨ Firmware mein kya milega?

- Router flash karte hi WiFi khud-b-khud ON ho jayegi (2.4GHz + 5GHz)
- Status LED — internet chalu hai toh **green**, band hai toh **red blinking**
- Model naam **runtime pe automatically detect** hota hai (MFG partition se)
- **Aurora theme** pre-installed aur default set
- Extra apps: WireGuard, SQM, nlbwmon, CPU/temp status, mwan3, zram, SCTP support

---

## 📥 Firmware kaha se download karein?

**Releases** section mein jao — wahan hamesha **latest firmware** milega, purani release automatically replace ho jaati hai.

---

## ⚠️ Zaroori baat

Flash karne se pehle apni original firmware ka backup zaroor rakhein.
